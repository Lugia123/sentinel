## 关键设计
- **每日追踪语义**:「添加自定义股票」→ 关注(source=user)→ 每天 run_daily 也算它(custom)。空 track 完全不变(保底)。portfolio.n_holdings 只数策略持仓。
- **AI 分配安全**:金融计算不信 AI 算术——权重服务端归一化、股数按现价确定性计算。
- **数据来源诚实**:财报=SEC EDGAR 真引用;背调=明确标注 AI 非实时检索、列核实渠道(不编造链接)。
- 新组件:SearchSelect / MultiSelect / Select / Modal / AllocateModal / EarningsChart / ProbBandChart。
