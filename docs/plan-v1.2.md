## P0 · 视觉地基(先做,后面全依赖)
- **#10 黑金设计规范**:用设计 skill 产出 `docs/design-system.md`——配色(黑底+金强调,涨绿跌红保留但更克制)、层级、字体、间距、组件规范、明暗态。后续风格调整只改这份 + tokens。
- **#8 Header + 布局**:顶部固定导航栏(Logo/版本 + 菜单:信号/持仓/走势/关注/帮助 + 右侧「重算」)。现在"按钮在上、菜单在下"的乱象重排。
- **#1 tooltip 修复**:InfoDot 弹框被表格 `overflow` 裁掉——改用 fixed 定位/portal 或提高 z-index + 让容器不裁剪。

## P1 · 数据主干(P3 走势的前提)
- **#3 定时 + 回填**:
  - 后台**定时任务**(Go cron):每日美股收盘后(约北京时间次日 05:30)自动跑引擎 + ingest。
  - **人工重跑按钮**:仅当天快照缺失时才需要(平时不用手动)。
  - **历史回填**:命令 `backfill --from 2026-01-01`,从起点每个交易日跑一遍补齐 snapshots/holdings/prices。⚠️**决策1:起点 + 耗时**——先测单日耗时,估总时长(全量含 SY 约 30s/日 → 25年起~3h,26年起~1h)。可能需先优化(SY 的 fp 打分是瓶颈,可跨日缓存基本面)。
- **MinIO 接入**:MinIO(localhost:9000),建 `sentinel` bucket,存大 HTML(背调/财报)。DSN/密钥进 server/.env。

## P2 · 标的元数据 + 交互
- **#9a 中文名 + 板块**:列表和详情显示中文公司名 + 板块(科技/金融…)。⚠️**决策3:数据源**——①我建一份静态映射表(覆盖 98 窄池 + 常见,一次性,离线可靠)②接 akshare/yfinance(yfinance 有英文行业,中文名需翻译)。倾向①先覆盖核心池。
- **#7 关注**:watchlist 表 + 列表关注按钮(★),关注的置顶,可取消。
- **#6 用户自定义分析**:输入任意 ticker → 用**同一起点**跑分析(即便"不好"也让看);标记 `source=ai|user` 区分。存同样的 snapshots/holdings 结构(或单独 user_analysis)。

## P3 · 分析走势界面(依赖 P1 回填数据)
4/5 一起设计成一个「**分析走势**」页:
- **#5 单股**:选一只 + 时间段 → 看它历史每天的 档位/概率带中位/相对强度/风险灯 等指标走势(折线)。
- **#4 多股**:选时间段 → 看多只(关注列表/AI选中)的某指标(如档位)走势对比(多线/热力图)。
- 统一:维度选择(单股/多股)× 指标选择(档位/中位收益/波动…)× 时间段。数据来自 P1 的历史 holdings 表。

## P4 · AI 升级(skill + MCP + HTML,存 MinIO)
- **#2 AI 讲解 → HTML**:讲解产出结构化 HTML(清晰分区、必要配图/图表),严格按 `internal/explain/RULES`。⚠️**决策2:AI 架构**——
  - 方案A(快):DeepSeek chat,数据塞 prompt → 生成 HTML(现在的讲解已是这条,升级成 HTML)。
  - 方案B(强):建 **Sentinel MCP server**(无认证,参考 Tinia `_shared/local-mcp`)暴露策略数据工具(get_snapshot/holding/history/prices)+ **skill**(规则+用法),让 agent 能自己拉数据做深度背调/财报。
  - 倾向:**讲解走 A**;**背调/财报走 B**(需要自己查资料的才上 MCP+agent)。DeepSeek 支持 function-calling,可在 Go 里做 tool 循环把 MCP 工具喂给它。
- **#9b 背景调查 tab**:AI 调查公司(做什么/行业排名/背景)→ 生成 HTML → 存 MinIO;详情页分 tab 展示 + 「重新背调」按钮。
- **#9c 财报解读 tab**:用户选季度 → 找财报文件(⚠️**决策4:财报来源**——SEC EDGAR 10-Q/10-K,已有 fp 基建可扩)→ AI 解读 → HTML → 存 MinIO;用户触发,不自动。

## 建议执行顺序
P0(视觉地基,立刻见效) → P1(数据主干,解锁走势)→ P2(元数据/交互)→ P3(走势页)→ P4(AI 升级,最大但最后)。
每阶段独立提交(版本 v1.2.N 累加)。
